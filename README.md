# 🕉️ Japa for Community — Japa Counter Web App

A devotional, mobile-friendly Japa counter that helps users track mantra chanting through manual taps or voice recognition. It features a traditional 108-bead mala experience, session history, daily goals, and lifetime chanting statistics.

---

## ✨ Features

- **🙏 Manual Japa Counter:** Increment the chanting count with a simple tap.
- **🎙️ Voice-Assisted Counting:** Recognize supported mantra words such as "Ram" or "Rama" using the Web Speech API.
- **🗣️ Live Speech Transcript:** Display recognized speech and microphone status.
- **📿 108-Count Mala Tracker:** Track progress through 108 repetitions and play a bell sound when a mala is completed.
- **🕉️ Mantra Selection:** Choose your preferred mantra.
- **📊 Statistics Dashboard:** View daily progress, session totals, and lifetime chanting statistics.
- **🎯 Daily Goals:** Set daily chanting targets and monitor progress.
- **📜 Session History:** Review previous chanting sessions.
- **💾 Data Persistence:** Store chanting progress, goals, and history using `localStorage`.
- **📱 Responsive Design:** Access the application on mobile, tablet, and desktop devices.
- **🌐 Offline-Friendly:** Support offline usage through local storage and optional PWA functionality.

---

## 🛠️ Technology Stack

- **React.js** — User interface and component management
- **Vite** — Development server and production builds
- **Tailwind CSS** — Responsive styling
- **Web Speech API** — Voice-based mantra recognition
- **Web Audio API** — Bell sounds and audio feedback
- **localStorage** — Local data persistence
- **Vite PWA / Service Worker** — Installable, offline-friendly experience
- **Lucide React** — Interface icons
